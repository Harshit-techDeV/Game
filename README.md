# Rock, Paper, Scissors Game

A lightweight, interactive web implementation of the classic **Rock, Paper, Scissors** game built using vanilla Web technologies. This project was developed to strengthen fundamental front-end web development concepts, DOM manipulation, and asynchronous game state logic.

---

## 🚀 Live Demo

Check out the live application hosted on GitHub Pages:  
[**Play Rock, Paper, Scissors**]( https://harshit-techdev.github.io/Game/)

---

## ✨ Features

* **Interactive Gameplay:** Play against an automated computer opponent with randomized choice generation.
* **Real-Time Score Tracking:** Dynamic state management updating scores without page refreshes.
* **Responsive Design:** Optimized layout for both mobile screens and desktop browsers.
* **Clean UI/UX:** Intuitive feedback for wins, losses, and ties.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structural markup.
* **CSS3:** Flexbox/Grid layout, custom variables, and transition animations.
* **JavaScript (ES6+):** Dynamic DOM updates, event handling, and core game logic.

---

## 🎯 Key Learnings & Development Insights

Building this project provided hands-on experience with fundamental web development concepts:

1. **DOM Manipulation & Event Handling:**  
   * Attached event listeners to interactive UI elements to trigger real-time game evaluations.
   * Dynamically updated text content, active states, and CSS classes based on game outcomes.

2. **Game State & Logic Design:**  
   * Modeled game outcomes using conditional statements and decision matrix logic.
   * Generated computer moves using JavaScript's `Math.random()` utility function.

3. **Responsive Web Design:**  
   * Structured layout using CSS Flexbox to ensure consistent rendering across different viewport sizes.

4. **Git & GitHub Pages Deployment:**  
   * Implemented version control workflows using Git.
   * Deployed static site assets directly using GitHub Pages.
